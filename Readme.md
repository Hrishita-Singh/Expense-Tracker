# 💰 Expense Tracker System

An industry-level Expense Tracker application to manage daily income and expenses, visualize spending habits, and set budget limits.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Chart.js
- **Backend:** Django, Django REST Framework (DRF)
- **Database:** PostgreSQL

## 📁 Project Structure
- `frontend/` - Contains the React dashboard, analytics charts, and Tailwind UI.
- `backend/` - Contains Django REST APIs, User Authentication, and PostgreSQL models.

## 👥 Team & Responsibilities
- **Project Leader:(Environment Setup, Git Management, Architecture)
- **Backend & DB Team:** Database models, PostgreSQL connection, Income/Expense APIs, User Auth.
- **Frontend & UI Team:** React components, Tailwind styling, Chart.js integration, API connection.
